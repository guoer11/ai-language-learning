# 驗證紀錄

## v0.5.1 語音辨識停止／離開修正

僅修改 SpeechRecognition 生命週期與修補版本標記；課程、計分、錄音回放功能、版面及 CSS 均未改動。原停止按鈕依賴 end 回呼解除 listening；原生 stop/abort 拋出例外亦可能中斷清理。現在先解除忙碌狀態、計時器與 callback，再嘗試 stop/abort，並攔截例外。15 秒未完成就自動停止；error、end、final result、offline、切換題目與 unmount 均會清理；舊 session 的晚到事件不會污染新的 session。

新增 16 項手機／桌面測試：停止後不回傳 end、停止後重新開始、辨識中按 X、15 秒無結果、權限拒絕、服務拒絕、網路錯誤、收音錯誤、無聲音、正常 end、只有 final result 沒有 end、實際切離線、建構／啟動／停止／abort 拋出例外、不支援辨識，以及晚到事件隔離。手機專案以 tap() 發送觸控輸入，沒有使用 force click；驗證停止與 X 可命中並操作，不靠增加 z-index 或透明遮罩處理。

這是 Chromium 手機尺寸／觸控模擬與 SpeechRecognition 替身測試，不是實體 iPhone Safari 的原生語音服務測試；Safari 的系統權限視窗、實際麥克風與服務連線仍需要實機確認。停止／逾時會保留已收到的文字，但中止後不再接收尚未送達的辨識結果。發音評分仍為 null／尚未評估，不生成假分數。

## v0.5.0 十題溝通練習

更新為 48 關、480 個題目實例；每關 10 題、兩題口說及兩題聽力。手機與桌面共 44 個測試案例，涵蓋 5 題正確不過關、6 題 1 星、8 題 2 星、10 題 3 星與 120 XP，十題完整答題／解鎖／弱點重練，以及舊版紀錄保留。

題庫檢查涵蓋 480 個唯一題目 ID、各選擇題四個不同選項且包含答案、填空可還原完整句子、每關至少七種不同教材文字、兩題口說使用不同句子，及所有日文教材／外語選項漢字都有讀音。新增情境教材的讀音隨原文保存，顯示和語音比對仍使用純文字。

兩次口說結果分別保存；語音辨識測試確認第一題的 browser 來源不會被最後一題手動輸入覆蓋。情境口說只是參考句比對，未實作自由回答／AI 發音評分；瀏覽器語音及裝置限制同下述 v0.2.0 說明。

## v0.4.0 答題／注音驗證

建置通過；手機與桌面共 42 案例。新增與更新的檢查包含：答對前 2 秒仍停留、3 秒後自動下一題、答錯停留 10 秒仍保留解析、離開關卡取消倒數；全對最後一題自動結算；細分排列中的重複助詞；每關翻譯／排列／聽力／口說教材不同；所有日文教材及日文選項的漢字都有讀音資料；舊進度保留，新紀錄使用 curriculumVersion:3。

漢字讀音以人工題庫標註，處理「何ですか」的 なん 與「何が」的 なに。不是任意使用者輸入的通用日文注音或文法判定服務。既有登入、語音 API 替身、錄音清理與離線流程仍保留驗證。

## v0.3.0 登入驗證

新增手機／桌面各 7 項登入測試：Google PKCE 與正確回跳 URL、一次性 callback exchange 與重載還原、帳號與訪客進度區隔、另一帳號不繼承紀錄、取消登入與清除 URL 錯誤參數、過期 code 不顯示成功、登出伺服器失敗的本機清理與提示。確認登出要求為 scope=local，翻譯 APP 的預設 session key 未被更動。

本節使用合成帳號與攔截 Auth API，未使用真實 Google 憑證；真實 Google 授權、正式 Redirect URLs 白名單與 iPhone 主畫面登入仍需完成驗證。未新增或驗證 learning_ 雲端資料表／RLS。
